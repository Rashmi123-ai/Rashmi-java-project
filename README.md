# Rashmi-java-project
# Rashmi Java Practice Repository

Welcome to my Java practice repository! This collection contains core Java programs covering Object-Oriented Programming (OOP) concepts, Data Structures, Algorithms, and fundamental mathematical/logical problems.

---

##  1. Object-Oriented Programming (OOP) Concepts

* **Encapsulation (`Encapsulation.java`)**: The technique of wrapping data (variables) and code acting on the data (methods) together as a single unit, keeping fields private and providing access via public getters/setters.
* **Inheritance (`InheritClass.java`, `inheritanceDemo.java`)**: The mechanism where one class acquires the properties and behaviors of a parent class using the `extends` keyword to promote code reusability.
* **Polymorphism (`PolymorphismDemo.java`)**: The ability of an object to take on many forms, primarily demonstrated through method overloading (compile-time) and method overriding (runtime).
* **Constructors (`constructor.java`)**: Special block of code called when an instance of an object is created to initialize fields.
* **Methods (`methods.java`, `calculatorUsingMethods.java`)**: Modular blocks of reusable code designed to perform a specific action or calculation.
* **Exception Handling (`exceptionHandling.java`)**: A mechanism to handle runtime errors (using `try`, `catch`, `finally`, `throw`, and `throws`) so the normal flow of the application is maintained.

---

##  2. Data Structures & Collections Framework

* **ArrayList (`arrayList.java`, `list.java`)**: Resizable array implementation of the `List` interface in Java, allowing dynamic element storage and manipulation.
* **HashMap (`HashMapDemo.java`)**: Data structure that stores elements in key-value pairs, using hashing for fast lookup, insertion, and deletion operations.
* **Stack (`StackDemo.java`)**: A linear LIFO (Last In, First Out) data structure supporting key operations like `push`, `pop`, and `peek`.

---

##  3. String Manipulation & Logic

* **String Comparison (`StringCompare.java`)**: Methods for comparing strings (e.g., using `.equals()` vs `==`) to evaluate equality by content versus memory reference.
* **Common Letters in Strings (`commonLettersInAString.java`)**: Algorithms to find character intersections or matching frequencies between string inputs.
* **Vowel Counting (`vowels.java`)**: String parsing logic to identify and count vowels ($a, e, i, o, u$).
* **Duplicate Parentheses (`duplicateParanthesis.java`)**: Stack-based string analysis to identify redundant or balanced nested parentheses in expressions.

---

##  4. Arrays & Searching Problems

* **Duplicate Elements (`duplicateArrays.java`)**: Methods to scan array elements and detect or remove duplicate entries.
* **Two Sum (`twosum.java`)**: Classic array problem finding two indices whose values sum up to a specific target value.

---

##  5. Recursion

* **Exponent using Recursion (`exponentUsingRecursion.java`)**: Calculating power $a^b$ recursively by multiplying the base $a$, $b$ times ($a \times a^{b-1}$).
* **Factorial using Recursion (`factorialUsingRecursion.java`)**: Computing $n!$ recursively using the relation $n! = n \times (n - 1)!$ with base case $0! = 1$.

---

##  6. Mathematical & Logical Problems

* **Armstrong Number (`armstrongnum.java`)**: Checking if an $n$-digit number equals the sum of its digits raised to the power $n$ (e.g., $153 = 1^3 + 5^3 + 3^3$).
* **Factorial (`factorial.java`)**: Iterative implementation to compute $n!$.
* **Fibonacci Series (`fibonacci.java`)**: Generating a sequence where each number is the sum of the two preceding ones ($F(n) = F(n-1) + F(n-2)$).
* **Prime Number (`primeNum.java`)**: Checking whether a number is greater than 1 and has no positive divisors other than 1 and itself.
* **Greatest of Numbers (`greatestOfTwoNums.java`, `greatestOfThreeNums.java`)**: Conditional logic (`if-else` / ternary operators) to compare multiple values.
* **Smallest Even Multiple (`SmallestEvenMultiple.java`)**: Calculating the smallest positive integer that is a multiple of both 2 and $n$.
* **Trailing Zeros in Factorial (`trailingZeroesInFactorial.java`)**: Mathematical approach to count trailing zeros in $n!$ by counting factors of 5 ($\lfloor n/5 \rfloor + \lfloor n/25 \rfloor + \dots$).
* **Combinations (`combination.java`)**: Implementing combinations math formula ${}^n C_r = \frac{n!}{r!(n-r)!}$.
* **XOR Operation (`XORoperation.java`)**: Bitwise XOR manipulation where bit output is 1 if inputs differ, commonly used in bit manipulation problems.
* **Buzz / Fizz Problem (`buzzFizz.java`)**: Logic problem printing specific responses based on divisibility rules (e.g., multiples of 3 and 5).
* **Temperature Conversion (`temperatureConvert.java`)**: Formulas for converting temperature between units (e.g., Celsius to Fahrenheit: $F = C \times \frac{9}{5} + 32$).

---

##  7. Patterns & UI/Printing

* **Print Square (`printSquare.java`)**: Nested loops generating square geometric grid patterns.
* **Star Patterns (`starPattern.java`, `starPatternPyramid.java`)**: Nested loop exercises generating line-by-line pyramid and triangle star configurations.
